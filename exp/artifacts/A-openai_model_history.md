# OpenAI 模型发展史：各产品线全景综述

> 资料检索与核实时间：2026 年 8 月 15 日。本文依据 OpenAI 官方发布页（openai.com/index）、官方 Help Center「Model Release Notes」、API 文档与弃用清单（developers.openai.com）以及 TechCrunch、The Verge、Ars Technica 等权威科技媒体报道整理，重要日期均经交叉核实。

OpenAI 自 2018 年发布 GPT-1 以来，八年间模型版图从单一的语言模型扩展为覆盖**语言、推理、视觉、图像生成、视频生成、语音、嵌入**的完整产品矩阵。纵观全貌，其发展大致可分为三个阶段：

1. **预训练时代（2018–2021）**：以「规模即性能」为信条，GPT-1 → GPT-3 参数规模扩大三个数量级；
2. **对齐与产品化时代（2022–2024）**：RLHF 对齐、ChatGPT 引爆消费市场，GPT-4/GPT-4o 确立多模态方向；
3. **推理与融合时代（2024–2026）**：o 系列把「测试时计算（test-time compute）」引入产品，随后推理能力并入 GPT-5 统一家族，模型以季度节奏快速迭代，并出现 Sol/Terra/Luna 分层命名。

## 二、GPT 系列：基础语言模型主线

### 2.1 奠基期：GPT-1 → GPT-3（2018–2020）

- **GPT-1（2018-06-11）**：论文《Improving Language Understanding by Generative Pre-Training》发表，117M 参数，在 BooksCorpus 上预训练后于 12 个下游任务微调，证明「生成式预训练 + 判别式微调」可行。
- **GPT-2（2019-02-14 初版，2019-11-05 完整版）**：OpenAI 因担心滥用采用罕见的**分阶段发布**策略，先放出 124M/355M/774M 版本，最终放出 1.5B 版本。其多任务零样本能力奠定「规模涌现」叙事，也是 OpenAI 最后一次全面开源 GPT 主干模型（直到 2025 年 gpt-oss）。
- **GPT-3（2020-05-28 论文，2020-06-11 API 内测）**：175B 参数，Few-shot 提示（in-context learning）成为新范式。同月即通过 API 商业化（Completions 接口，ada/babbage/curie/davinci 四个规格），2021-11-18 取消等待名单全面开放——OpenAI 的「模型即服务」商业模式由此确立。

### 2.2 对齐与 ChatGPT 时代：InstructGPT 与 GPT-3.5（2022–2023）

- **InstructGPT（2022-01-27 论文）**：首次系统应用 **RLHF**（人类反馈强化学习），1.3B 的对齐模型即可在人类偏好上胜过 175B 的 GPT-3，成为 text-davinci 系列的训练范式。text-davinci-002 于 2022 年 3 月上线，text-davinci-003 于 2022-11-28 发布。
- **ChatGPT（2022-11-30）**：基于 GPT-3.5 的对话优化版，5 天用户破百万，是 AI 史上最重要的产品时刻。其 API 版 **gpt-3.5-turbo** 于 2023-03-01 随 Chat Completions 接口上线，以 GPT-3 十分之一的价格成为当时开发者的事实标准。

### 2.3 GPT-4 与 Turbo（2023）

- **GPT-4（2023-03-14）**：支持 8K/32K 上下文，并首次原生接受**图像输入**（发布初期视觉能力仅对合作方开放）。API 于 2023-07-06 全面可用（gpt-4-0613 起支持函数调用）。**GPT-4V（2023-09-25）** 将视觉理解推入 ChatGPT 产品。
- **GPT-4 Turbo（2023-11-06，首届 DevDay）**：128K 上下文、知识截止更新、JSON 模式、并行函数调用、视觉输入，并大幅降价。gpt-4-turbo（2024-04-09）将视觉能力 GA。GPT-4 系列确立了「多模态大模型」的行业模板。

### 2.4 GPT-4o：原生多模态（2024）

- **GPT-4o（2024-05-13）**：o 即 omni，一个 Transformer 端到端处理**文本、图像、音频**的输入与输出，官方称音频响应延迟最快 232ms、平均约 320ms，接近真人对话。首次向免费用户开放，并于 2024-08-06、2024-11-20 等快照持续增强。
- **GPT-4o mini（2024-07-18）**：以极低成本（$0.15/$0.60 每百万 token）覆盖多数常规任务，成为全球用量最大的 API 模型之一。

### 2.5 过渡期：GPT-4.1 与 GPT-4.5（2025 上半年）

- **GPT-4.5（2025-02-27，研究预览）**：沿「无监督学习放大」的非推理路线继续扩展，以「情商」、减少幻觉、写作与对话自然度见长，gpt-4.5-preview 于 API 提供。它是 GPT-4 系谱的最后一代，也是 GPT-5 统一前的过渡。
- **GPT-4.1 家族（2025-04-14）**：面向 API 开发者发布 gpt-4.1、gpt-4.1-mini、gpt-4.1-nano，主打 **100 万 token 上下文**、更强的编码与长文档理解。ChatGPT 中并未提供该系列，是「API 优先」策略的体现。

### 2.6 GPT-5：统一家族（2025-08）

- **GPT-5（2025-08-07）**：不再区分「推理模型」与「聊天模型」，而是一个**路由系统**：按任务难度与用户选择的思考等级（low / medium / high）自动调度内部不同规模模型（发布时 high 档路由至 o4-mini）。家族包含 gpt-5、gpt-5-mini、gpt-5-nano 三档；gpt-5 输入上下文约 27 万 token（GPT-5 Pro 为 40 万），输出上限 12.8 万 token。定价激进（$1.25/$10），被媒体称为「价格战」。所有 ChatGPT 用户（含免费版）均可使用。
- **GPT-5 Pro（2025-10-06 上 API）**：为高难度任务提供显著更强的推理（$15/$120 每百万 token），成为当时最强的 API 模型。

### 2.7 快速迭代期：GPT-5.1 → GPT-5.6（2025-11 ~ 2026-07）

| 版本 | 发布 | 要点 |
|---|---|---|
| GPT-5.1 | 2025-11-12（API 11-13） | 自适应推理（简单问题少思考、难题多思考）；推出 **gpt-5.1-codex / gpt-5.1-codex-mini** 编码专用模型 |
| GPT-5.2 | 2025-12-11 | 面向科学与数学的专项强化 |
| GPT-5.3-Codex | 2026-02-05 | 编码旗舰迭代；同月 **GPT-5.3 Instant** 成为 ChatGPT 日常对话默认模型 |
| GPT-5.4 | 2026-03-05 | 标准版与 Pro 版，全面增强推理与工具使用 |
| GPT-5.5 | 2026-04-23 | 100 万 token 上下文；API 用 `reasoning.effort`（none/low/medium/high/xhigh）替代分档；gpt-5.5 定价 $5/$30，gpt-5.5-pro $30/$180 |
| GPT-5.6 | 2026-06-26 预览，2026-07-09 GA | **Sol（旗舰）/ Terra（均衡）/ Luna（轻量）** 三层家族，1.05M 上下文、128K 输出上限；新增 max 推理档、ultra 模式（子智能体并行）、显式提示缓存断点。定价：Sol $5/$30、Terra $2/$12、Luna $0.20/$1.20 |

> 从 GPT-5 到 GPT-5.6，OpenAI 放弃了「型号数字 + mini/pro 后缀」的传统命名，转向**世代 + 性格分层**（Sol/Terra/Luna），且迭代节奏压缩到每月一次，创下其历史上最快的旗舰更新频率。

### 2.8 gpt-oss：开放权重（2025-08-05）

2025-08-05，OpenAI 发布 **gpt-oss-120b（总参 117B）与 gpt-oss-20b（总参 21B）**，Apache 2.0 协议，采用 MoE（混合专家）架构，可直接在 Hugging Face 下载，20B 版可跑在 16GB 显存的消费级硬件上。这是自 GPT-2 之后 OpenAI 首次开放权重，标志着其「闭源 API + 开放权重」双轨战略。

## 三、o 系列：推理模型专线

o 系列的核心创新是**强化学习 + 思维链（Chain-of-Thought）**：模型在回答前生成隐藏的推理过程，「思考时间越长、答案越好」，即测试时计算缩放（test-time compute scaling）。

- **o1-preview / o1-mini（2024-09-12）**：首发推理模型。在数学、编程、科学基准上大幅超越 GPT-4o（如 AIME 数学竞赛得分从约 13% 提升到 57% 量级）。o1-mini 提供低成本推理。
- **o1 正式版 + o1 pro mode（2024-12-05，12 Days of OpenAI 第 1 天）**：同日发布 **ChatGPT Pro**（$200/月），o1 pro mode 以更多算力换更高可靠性，仅 Pro 可用。API 端 o1 于 12-17 对高等级开发者全面开放。
- **o3 / o3-mini 预告（2024-12-20，12 Days 第 12 天）**：o3 预览版在 **ARC-AGI** 基准高算力设置下取得 **87.5%**，逼近人类水平，引发「AGI 已至」的讨论。**o3-mini（2025-01-31）** 率先落地，成为首个免费开放的推理模型。
- **o3 + o4-mini（2025-04-16）**：推理模型首次获得**完整工具使用权**——在思维链内部调用网络搜索、Python 解释器、文件分析等；同时具备**视觉推理**（可对上传图像裁剪、旋转、放大后再思考），并采用「深思熟虑对齐」（模型用自身推理能力理解安全规范）。o4-mini 发布时即声称 AIME 满分。
- **o3-pro（2025-06-10）**：o 系列顶点，在 ChatGPT 中取代 o1 pro mode，为 Pro/Team 用户提供最高可靠性推理。
- **并入 GPT-5（2025-08-07 起）**：GPT-5 发布后，o 系列作为独立品牌淡出——推理能力成为 GPT-5.x 家族中由思考等级/`reasoning.effort` 控制的「一档能力」而非独立产品线。官方至今未发布 o5。

> 技术意义：o 系列把「推理算力」变成产品参数，并催生了 deep research（2025-02-02）、Operator（2025-01-23）等智能体应用，最终沉淀为 GPT-5 的 thinking 档位。

## 四、多模态：视觉理解、图像与视频生成

### 4.2 图像生成：DALL·E → GPT Image

| 模型 | 发布时间 | 要点 |
|---|---|---|
| DALL·E | 2021-01-05 | 12B 参数，dVAE + 自回归 Transformer，首个大规模文本→图像模型 |

### 4.3 视频生成：Sora

- **Sora（2024-02-15 预告，2024-12-09 进 API）**：以分钟级一致性、物理与运镜理解引发全球关注；API 版提供 sora / sora-turbo 两档。
- **Sora 2 / Sora 2 Pro（2025-09-30）**：支持**同步音频生成**、更高的物理一致性、更高分辨率与更长镜头；Pro 版面向专业用户，随 ChatGPT Pro 提供。

## 五、语音

### 5.1 Whisper：开源转写

- **Whisper（2022-09-21）**：论文与 MIT 协议开源同步发布，68 万小时多语言监督数据训练，鲁棒性与零样本跨语言能力远超当时商业 ASR，成为行业事实基准（衍生出 faster-whisper 等生态）。
- **版本演进**：large-v2（2022-12-08）→ **large-v3（2023-11-06）** → **large-v3-turbo（2024-09-30）**，解码层从 32 减至 4 层、速度提升约 8 倍而精度损失极小。开源库持续维护（如 2025-06-25 的 v20250625）。
- **API 侧**：whisper-1 自 2023-03-01 提供服务，2025-03-20 起被新一代 **gpt-4o-transcribe / gpt-4o-mini-transcribe** 取代（词错误率显著下降、可引导风格），并持续迭代快照（如 2025-12-15 版本）。

### 5.2 TTS 与语音对话

- **TTS API（2023-11-06，DevDay）**：tts-1 / tts-1-hd 六种音色；ChatGPT 移动端语音对话于 2023-09-25 上线（Whisper + TTS 管线）。
- **GPT-4o 原生语音（2024-05-13）**：端到端语音对话演示；**Advanced Voice Mode** 2024-07-30 alpha、2024-09-24 起大范围推送，支持打断、情感与语气变化。
- **gpt-4o-audio-preview（2024-10-01）**：Chat Completions 接口获得音频输入输出能力。
- **gpt-4o-mini-tts（2025-03-20）**：可引导 TTS——用自然语言控制语气、情感、口音甚至发音（如"像海盗一样说话"）。
- **Realtime API**：2024-10-01 beta（gpt-4o-realtime-preview，WebSocket/WebRTC 低延迟语音对话）；**gpt-realtime（2025-03-20 推出，2025-08-28 GA）**：面向生产级语音代理，支持 SIP 电话接入、MCP 服务器与图像输入，指令遵循与工具调用显著增强。

## 六、嵌入与其它 API 模型

### 6.1 嵌入模型三代演进

| 代际 | 模型 | 时间 | 说明 |
|---|---|---|---|
| 第一代 | text-search-* / text-similarity-* / code-search-* 系列 | 2021–2022 | 基于 GPT-3 的 ada/babbage/curie/davinci 规格，2024-01-04 全部退役 |
| 第二代 | text-embedding-ada-002 | 2022-12-15 | 五模型合一，1536 维，价格降至原 davinci 的 1/100；至今仍在服务（官方建议新项目不再使用） |
| 第三代 | text-embedding-3-small / 3-large | 2024-01-25 | **Matryoshka 表示学习**：可截断维度（如 3072→256）不重训，性能提升同时大降价（small $0.02/百万 token、large $0.13/百万 token） |

截至 2026-08，text-embedding-3 仍是官方推荐代际，尚无新一代嵌入模型发布。

### 6.2 其它

- **Codex（2021-08-10 内测）**：code-davinci-002 / code-cushman-001，GitHub Copilot 的首个底座；2023-03-23 随 ChatGPT/Code Interpreter 崛起而退役。2025 年「Codex」品牌以**智能体编码产品**身份复活（云端 Codex 2025-05，Codex CLI 开源）。
- **审核模型**：text-moderation 系列（2022 起）→ **omni-moderation-latest**（2024），支持文本+图像的多模态安全审核。
- **微调能力**：2023-08-22 开放 gpt-3.5-turbo 微调，此后 gpt-4o（2024-08）、GPT-4.1、GPT-5 家族逐步支持，构成 API 产品线的定制化能力层。

## 八、结语：八年的三条主线

1. **从「更大」到「更会想」**：参数规模竞赛（2018–2023）让位于推理算力与思维链（2024–2026）；o 系列的遗产不是某个模型，而是「思考深度作为产品参数」这一设计。
2. **从单模态到全模态**：文本 → 图像理解 → 图像生成 → 音频 → 视频，且各模态收敛到同一模型（GPT-4o → GPT-5 → gpt-image-2 的「会推理的图像模型」），「一个模型做所有事」的 omni 愿景逐步兑现。
3. **从模型公司到平台公司**：API 从单一 Completions 接口演进为 Responses/Realtime/嵌入/微调/智能体的完整平台；命名体系从型号数字演化为世代分层（Sol/Terra/Luna）；开放权重（gpt-oss）与闭源旗舰并行——三条产品线（消费级 ChatGPT、开发者 API、开放权重）各自独立迭代、共享技术底座。
